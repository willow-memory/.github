# Support

Questions and ideas: open a GitHub issue on the relevant repo — the
templates keep it quick. Security findings: see
[the security policy](https://github.com/willow-memory/.github/blob/main/SECURITY.md)
instead.

These are local-first platform tools maintained by one person and a small fleet
of agents; responses are usually fast, occasionally not. Issues with
receipts (exact commands, real output) get fixed first.
